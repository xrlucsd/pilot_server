# XR Lab experiment

Shared terminology for the participant tasks in the XR Lab experiment.

## Language

**MAT**:
The math test in which a participant starts with a given number and repeatedly subtracts a fixed amount from each successive result.

**SART**:
The spacebar number task in which numbers appear sequentially and the participant presses the spacebar for most numbers but withholds the response for a designated target number. The target is often `3`, but that value is not a universal protocol requirement.

**PRS (Perceived Restorativeness Scale)**:
A task asking participants to rate how well statements describe their experience in the room on a 0–6 scale, then briefly explain each rating. The scale runs from 0 ("Not at all") to 6 ("Completely").

**ZIPER**:
Surveys completed by the participant between tasks to measure personal reactions.

**IPR**:
A provisional synonym for ZIPER; the lab's current understanding is that these refer to the same surveys.

**PSS (pre-screening surveys)**:
The lab's term for surveys used for participant pre-screening.
